## seal.png (아직 없음)

고려대학교 ANCHOR사업단장 직인 이미지를 `seal.png` 이름으로 이 폴더에 넣으세요.

- 배경이 비치는 PNG(투명 배경)를 권장합니다.
- 정사각형에 가깝게 잘라 주세요. 수료증에는 18mm × 18mm로 들어갑니다.
- 넣지 않으면 수료증에 점선 자리만 찍힙니다. **그 PDF는 정식 수료증이 아닙니다.**

이 폴더는 `.gitignore` 대상입니다. 직인 이미지는 GitHub에 올리지 않습니다.
