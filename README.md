# ANCHOR 수료증 발급

고려대학교 ANCHOR사업단 프로그램 수료자가 **자기 수료증을 직접 발급**받는 웹 앱입니다.

담당자가 엑셀로 수료자 명단을 올려두면, 학생이 학번과 이름을 입력해 국문 또는 영문 수료증을
화면에서 확인하고 PDF로 내려받습니다.

---

## 무엇을 하는 앱인가

### 학생 (로그인 없음)

```
학번 · 이름 입력  →  수료한 프로그램 선택  →  수료증 확인  →  PDF 받기
```

- 학번과 이름이 **둘 다** 맞아야 조회됩니다.
- 자기가 실제로 수료한 프로그램만 목록에 나옵니다.
- 국문과 영문 중에서 고를 수 있습니다.

### 담당자 (사업단 공용 계정)

```
로그인  →  엑셀 명단 서식 받기  →  채워서 올리기
```

- 잘못된 줄이 하나라도 있으면 **한 건도 저장되지 않고**, 몇 번째 줄이 왜 틀렸는지 알려줍니다.
- 비밀번호를 직접 바꿀 수 있고, 잊었을 때는 사업단 공용 메일로 재설정 링크를 받습니다.

## 화면

| 주소 | 무엇 |
|---|---|
| `/` | 학생 수료증 발급 |
| `/admin` | 담당자 명단 관리 (로그인 필요) |
| `/admin/login` | 담당자 로그인 |
| `/admin/password` | 비밀번호 변경 |

## 만든 방식

| | |
|---|---|
| 화면과 서버 | Next.js (App Router, TypeScript) |
| 배포 | Vercel |
| 명단 보관 | Supabase — 값이 없으면 로컬 파일로 대체 |
| 엑셀 | ExcelJS |
| 값 검사 | Zod |
| PDF | 서버 안의 크롬(Puppeteer)으로 A4 한 장을 찍음 |
| 글꼴 | 수료증은 본명조(Noto Serif KR), 화면은 맑은 고딕 → Noto Sans KR |

### 왜 PDF를 서버에서 만드나

수료증에는 사업단장 직인이 들어갑니다. 브라우저에서 PDF를 만들면 **직인 이미지가 학생
컴퓨터로 내려가** 다른 문서에 붙이면 가짜 수료증이 됩니다.

그래서 직인 이미지는 웹으로 내려받을 수 없는 `private/` 폴더에 두고, 서버에서 PDF 안에만
넣습니다. 화면 미리보기에는 직인 대신 점선 자리만 보여줍니다.

### 화면과 PDF가 어긋나지 않는 이유

수료증 서식은 `src/lib/certificate.ts` **한 파일**이고, 화면 미리보기와 PDF가 그것을 함께
씁니다. 서식을 두 벌 만들면 시간이 지나면서 반드시 어긋납니다.

## 지켜야 할 규칙

이 앱이 다루는 것은 개인정보(학번·이름·이메일)와 공식 증서입니다. 아래는 고쳐서는 안 되는
규칙입니다. 자세한 근거는 [prd_lite.md](prd_lite.md)에 있습니다.

- **단위과제번호와 프로그램번호는 글자로 다룹니다.** 숫자로 다루면 `01`이 `1`이 되어 관리번호가 틀어집니다.
- **엑셀 업로드는 전부 아니면 전무입니다.** 절반만 저장되면 명단이 어긋난 채로 남습니다.
- **PDF에 한글 글꼴을 포함시킵니다.** 포함하지 않으면 한글이 네모로 깨집니다.
- **직인 이미지는 공개 폴더에 두지 않습니다.**
- **조회 실패 시 어느 항목이 틀렸는지 알려주지 않습니다.** 남의 정보를 캐는 단서가 됩니다.
- **학번과 이름을 주소창에 남기지 않습니다.**

## 내 컴퓨터에서 돌려보기

```bash
npm install
npx puppeteer browsers install chrome
npm run dev
```

`.env.local` 파일을 만들어 아래 값을 채웁니다. 이름은 [.env.example](.env.example)을 보세요.

```
ADMIN_ID=              담당자 공용 아이디
ADMIN_PASSWORD=        숫자 네 자리
SESSION_SECRET=        임의의 긴 문자열
```

Supabase 값이 없으면 명단이 `.data/roster.json` 파일에 저장됩니다. 내 컴퓨터에서 개발할
때만 그렇고, **Vercel에서는 파일을 쓸 수 없으므로 배포 전에 Supabase 값이 필요합니다.**

### 확인용 스크립트

개발 서버를 띄운 뒤 실행합니다.

```bash
npx tsx scripts/check-roster.mts   # 명단 읽기·검증 19가지
npx tsx scripts/compare.mts        # 미리보기와 PDF가 같은지
npx tsx scripts/sweep.mts          # 합성 명단 31건 전체 흐름
```

## 넣어야 할 값

| 이름 | 무엇 | 없으면 |
|---|---|---|
| `ADMIN_ID` `ADMIN_PASSWORD` | 담당자 공용 계정 | 로그인 불가 |
| `SESSION_SECRET` | 쿠키·재설정 링크 위조 방지 | 로그인 불가 |
| `SUPABASE_URL` `SUPABASE_SERVICE_ROLE_KEY` | 명단 보관 | 로컬 파일로 대체 (Vercel에서는 동작 안 함) |
| `ADMIN_EMAIL` `MAIL_FROM` | 비밀번호 재설정 메일 | 재설정 메일만 안 됨 |
| `RESEND_API_KEY` 또는 `SMTP_*` | 메일 보내는 방법 | 재설정 메일만 안 됨 |
| `APP_URL` | 메일에 넣을 링크 주소 | 접속한 주소를 그대로 씀 |

**비밀 값은 `.env` 또는 Vercel 설정에만 넣습니다. 코드에 직접 쓰지 않습니다.**

## 아직 준비되지 않은 것

- **직인 이미지** — `private/seal.png`에 실제 직인을 넣어야 합니다. 지금은 "임시 직인"이라고
  적힌 자리표시용 그림이 들어 있습니다. **그 상태로 나온 PDF는 정식 수료증이 아닙니다.**
- **Supabase 연결** — 배포해서 실제로 쓰려면 필요합니다.
- **메일 설정** — 비밀번호 재설정 메일을 쓰려면 필요합니다.
